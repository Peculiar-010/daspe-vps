How it works

From code to live
in under 2 minutes.

No configuration hell. No infrastructure management. Connect GitHub or upload files, configure your runtime, and deploy.

01

Request Access

Sign in with GitHub. Your application is reviewed and approved by the platform admin before you can deploy anything.

02

Choose Your Runtime

Select a language runtime or write your own Dockerfile. Connect your GitHub repo or upload files directly.

03

Add Your Secrets

Set encrypted environment variables for API keys, database URLs, tokens — anything sensitive. Masked in the UI, encrypted at rest.

04

Deploy & Monitor

Hit deploy. Watch real-time build logs. Your project goes live on a subdomain of daspe.name.ng. Uptime monitoring starts automatically.
